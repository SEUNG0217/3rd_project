# 역할 브리핑 사용법

이 폴더의 파일은 **AI가 읽고 나에게 설명해 주는 용도**입니다. 혼자 다 읽고 이해할 필요는 없습니다.

## 시작하는 법 (복사해서 AI에게 그대로 보내기)

```
docs/roles/(내 역할 파일).md 를 읽어.
너는 이 프로젝트에서 내 사수야. 나는 이 프로젝트에 처음 들어왔고 코딩이 익숙하지 않아.
1. 먼저 내가 맡은 일이 무엇이고 전체에서 왜 필요한지 쉬운 말로 5줄 안에 설명해 줘.
2. 그다음 "할 일"의 1단계만 같이 하자. 내가 직접 따라 할 수 있게 하나씩 알려 줘.
3. 단계가 끝날 때마다 "확인 방법"대로 내가 직접 확인하게 하고, 내가 "다음"이라고 하면 다음 단계로 가.
4. 이 문서 범위를 벗어나는 일이 생기면 멈추고 "팀장에게 물어볼 것"이라고 알려 줘.
```

중간에 이해가 안 되면 그냥 "방금 거 더 쉽게 설명해 줘", "왜 이걸 해야 해?"라고 물어보면 됩니다.

## 역할 파일

| 파일 | 역할 | 한 줄 설명 |
| --- | --- | --- |
| `A_크롭탐지.md` | 팀원 A | PDF 페이지에서 표·차트를 정확히 오려 내는 부분 |
| `B_추출품질.md` | 팀원 B | AI가 읽어 낸 표 숫자가 맞는지 확인하고 정답지를 만드는 부분 |
| `C_검색.md` | 팀원 C | 검색어를 넣으면 맞는 표·차트가 위에 나오게 하는 부분 |
| `D_백엔드.md` | 팀원 D | PDF 업로드·진행률·검수 기록을 처리하는 서버 부분 |
| `E_화면.md` | 팀원 E | 사용자가 보는 웹 화면 |

팀장은 여러 문서의 같은 지표를 모아 비교하는 엔진과 전체 통합을 맡습니다.

## 프로젝트 전체 흐름 (모든 역할 공통)

```
PDF 업로드 ─▶ 페이지에서 표·차트 오려 내기 ─▶ AI가 내용 읽기 ─▶ 확신도 계산 ─▶ 저장(Qdrant)
  [D,E]           [A]                         [B]               [B]              [C]
                                                                    │
                     0.80 미만이면 검수 대기 ─▶ 사람이 검수 ─▶ 승인되면 검색에 노출
                                              [D,E]
검색어 입력 ─▶ 맞는 요소 찾기 ─▶ 카드로 보여 주기 ─▶ 두 개 골라 비교 / 원문 페이지로 이동
  [E]            [C]              [E]                [팀장, E]
```
